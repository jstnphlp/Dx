# Company command center

## Outcome

- Give authenticated users a coherent view of active people, projects, reviews, work sessions, and company activity.
- Home metrics and attention items are derived from the versioned browser demo store used by the represented operational routes.
- Durable company reporting, production presence, and authoritative auditing are excluded.

## Access and data

- Every authenticated starter user can use the prototype and all prototype controls.
- The authenticated user replaces the seeded Nico R&D persona. Data is isolated by user ID in browser storage and validated before hydration.
- Activity is local product history, not a security audit record.

## Acceptance

- `/dashboard` shows the preview 6 command-center structure using the existing design system.
- Project, schedule, output, and time changes update KPIs, attention, presence, and activity without a refresh.
- Activity can be filtered and contextual links open the relevant project workspace.
